# Python-solutions
Hi! This is a collection of 11 Python programs I wrote from scratch while learning the basics of programming. I wanted to practice logic, user input, and problem-solving by building small tools that actually do useful things, including a couple of simple rule-based chatbots since I am really interested in AI.
What is Inside
AI and Chatbots
Simple Rule-Based AI Chatbot.py - A basic chatbot that replies to user messages using preset rules.
Custom Rule Based Bot Creator.py - Lets you create your own custom questions and answers for a simple bot.
Data and Math Tools
Interactive Chart and Graph Generator.py - Turns numbers you enter into visual charts and graphs.
Student Marks and Result Analyzer.py - Takes student marks and calculates totals, percentages, and results.
Automatic Statistics Calculator.py - Finds basic stats from a list of numbers automatically.
Automatic Multiplication Table Generator.py - Prints out multiplication tables for whatever number you pick.
Simple Calculator.py - A straightforward command-line calculator for basic math.
Everyday Utilities
Retail Shop Billing Calculator.py - Adds up items and calculates the final bill for a small shop.
Employee Salary Calculator.py - Calculates employee pay based on basic salary inputs.
Vehicle Service Reminder System.py - Keeps track of vehicle maintenance dates and reminds you when service is due.
Personal Data Storage System.py - A simple program to save and look up personal records.
How I Made These:
Based on my school knowledge of coding i designed solution to simple problems first.
